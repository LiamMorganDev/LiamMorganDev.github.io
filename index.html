about.md
Currently building at Firefish Software

I build full-stack software end to end — APIs, databases, the cloud infrastructure behind them, and the UI on top. C#, TypeScript and React at work; Docker and self-hosted Linux for everything I run myself.

I'm deep into the AI development side of things too — I lead the rollout of AI tooling for developers at work, and Claude Code is part of my daily workflow, not a novelty. It's one of the more interesting shifts I've seen in how software actually gets built, and I like staying close to where that's heading.

I like building for people I actually know — a gym that needed to stop chasing cash payments, a print shop that needed an online storefront.

Outside of work: self-hosting, Brazilian Jiu-Jitsu, and gaming.
